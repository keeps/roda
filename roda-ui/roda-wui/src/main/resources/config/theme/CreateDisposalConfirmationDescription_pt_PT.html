Nesta página pode ver as entidades cujo prazo de retenção expirou. Se as entidades intelectuais estão prontas para eliminação é possível associá-las a um novo auto de eliminação ou alterar a sua tabela de seleção. Se as entidades intelectuais estão prontas para revisão, apenas é possível alterar a sua tabela de seleção. Além disso, também é possível ver entidades intelectuais cujo cálculo do prazo de conservação tenha falhado.
